Clique nos tópicos abaixo para descobrir algumas curiosidades sobre tecnologia.

Como surgiu a internet

A internet surgiu a partir de pesquisas e projetos de comunicação entre computadores.
Um dos projetos mais importantes foi a ARPANET na década de 1960.

O que significa HTML?

HTML significa Linguagem de marcação de Hipertexto e é usado para estruturar conteúdo

Para que serve o CSS?

O CSS (Cascading Style Sheets ou Folhas de Estilo em Cascata) serve para definir a aparência visual e o layout de páginas da web escritas em HTML.

Para que serve o JavaScript

Enquanto o HTML cria a estrutura de um site e o CSS cuida das cores e do visual, o JavaScript atua como o cérebro que dá vida à página
O JavaScript serve para adicionar interatividade, dinamismo e lógica a páginas da internet e aplicativos.

Como publicar um site?

Para publicar um site na internet, você precisa de um domínio (o endereço web), uma hospedagem (o servidor que guarda os arquivos) e os arquivos do site prontos
